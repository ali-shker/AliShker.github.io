Run locally
This is a lightweight static website with no build step.

git clone https://github.com/ali-shker/alishkerportfolio.git
cd alishkerportfolio

Start a local server from the project directory:

python3 -m http.server 4173

Then open:

http://localhost:4173

You can also use the Live Server extension in VS Code.
